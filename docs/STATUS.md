## 4. 关键技术决策与踩坑(AI 必读,勿重蹈)

**时钟与音频**

1. **歌曲时间只用歌曲/AudioContext 时钟**(`TimelineClock(() => soundscape.clockSeconds())`)。嵌入式 webview 中 rAF/`performance.now()` 可能与音频时钟不同基准(曾实测 7 秒跳 30 秒)。`performance.now()` 仅用于指针活跃判断。
2. **歌曲模式下一切时间判断必须先 `await soundscape.start()` 再读 `songMode`**(加载发生在 start 内);时间线起点 t0=4(歌起),录制的 t0 必须与之一致(回放用 `recording.t0`)。
3. **togglePause 恢复顺序**:必须先 `state.paused = false` 再 `soundscape.resume()`(resume 内部检查该标志决定是否重启歌曲,顺序反了时钟冻结)。
4. **`soundscape.measure(dt)` 只允许引擎 step 调用**(内部 EMA/冷却按调用推进,调试代码再调会双倍速率、节拍失效)。调试只读 `__inkState.energy/beatFlash/debugScrollPct`。
5. 母带响度大的歌,频域 byte 数据全频段饱和,**能量用时域 RMS 映射**,节拍用 RMS 通量(慢 EMA + 相对/绝对双阈值)。
6. **seek 会使录制失效**(`state.recording = null`,设计如此)。回放中禁用 seek。随机数一律 `state.rng()`(种子化),`Math.random()` 破坏回放确定性。

**编舞与内容**

7. **编舞时间 = 歌曲时间 + 4s** 视频前导;`DURATION=244`(视频)vs 歌曲 233.7s。偏移被 5 处独立对齐验证(唇 91s、大喷溅 70.5s、高潮 172.7s 等)。
8. **图形出现时线条必须连续**(原版图形从流动墨迹中浮现,不停笔)。"提笔断点"是错误设计,已移除。导演编舞的停笔存**世界坐标**(笔钉在纸上随滚动左移、墨积深、从出口锚点续笔)。
9. 黑屏转场是**两阶段**:40–41.8s 黑幕+发光窗口(树下小人)→ 41.8–42.8s 回白纸+深色戴帽人剪影(fx 层)。黑幕全程盖住第二阶段曾是真 bug。
10. 148–151s 墨滴模式**抑制一切 cue 精灵**(只留竖直滴落+尾迹+落点溅射)。
11. **AI 目测帧位移估算不可信**(曾把滚动估成 4.7-6.3%/s,互相关实测 17-57%,差 4-10 倍)。速度类校准必须用 `tools/measure_scroll.py`。

**笔刷与笔迹**

12. **笔刷方向角必须用速度方向的 EMA 平滑**(`b.dirAngle`),不能用逐步位移 `atan2` — 120Hz 微步长下方向乱跳,墨迹碎成"节点+管子"。
13. **笔刷弹簧系数与坐标尺度无关**(积分器 `vel += ((target-pos)×spring - damping×vel)×dt` 中 spring 无量纲)。参考引擎 spring=90/damping=14;曾误算成 15-24 导致跟手迟钝。
14. **滚动绝不能用"每步整屏拷贝"**(旧 shiftInk:高潮 240 次全屏复制/秒,变速即卡顿)。现行:世界画布 + 每帧一次取景 blit + 相机过 1.5 屏宽时整体左移一屏(数秒一次)。**所有持久墨迹对象(ribbon 样本/墨池/粒子/图形/墨滴)一律世界坐标、恒等变换绘制** — 曾出现"出生加 cameraX、绘制又平移"的双重平移 bug,以及**回卷时漏 rebase ribbon 样本**导致整屏直线。
15. **笔迹=连续条带窗口重绘**:120Hz 采样进 48 样本(0.4s)窗口,每帧构建**单一连续闭合多边形**(上缘前进+下缘回退+closePath)填充。每位置约 24 次叠印 → 实心浓墨(6/255)、高速不断点。**绝不能把上/下缘建成两个独立子路径** — `fill()` 会用隐式直线闭合每个子路径,闭合弦在曲线内侧累积成浅灰弦线网格(用户实测报告过)。**世界回卷时必须同步平移窗口内样本**。
16. 持久墨层上的 print 精灵**只提交一次**(0.3s 淡入后停);运动型图形(鸟/蝶/小鱼/气泡)持续轻印(alpha~.13)留轨迹。
17. **光标环只能画在 fx 层**(每帧清除),且仅在笔刷缓停(速度<220×scale 持续 0.35s)时显示。
18. **滚动公式**(能量驱动,`score.scroll` 已废弃):`min(58, velocidad × 2.1 × (4 + 15.5×energy + 14×climax) × (1 + .4×pointerBias))` %/s;原版互相关实测:中段 17-22、强段 38、高潮 53-57。指针偏右滚动加速是原版相机行为；但**画笔位置不应人为钳在 8%-70%**：Pablo 引擎记录的是全舞台原始指针坐标，现仅把越界值裁回画布 `[0,width]×[0,height]`，触控可用完整宽高。

**调试**

19. `window.__inkState = state`、`window.__inkSoundscape = soundscape` 是自动化调试句柄。
20. **细结构验收必须给 qwen 放大裁剪图 + 像素统计交叉验证**:全图快照验收曾两次误判(把实心带看成线束);像素扫描(窄段计数/亮度分布)是客观尺子,用户实测截图是最真实的回归样本。
