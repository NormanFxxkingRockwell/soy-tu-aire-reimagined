## 4. 关键技术决策与踩坑(AI 必读,勿重蹈)

1. **时钟只用 `performance.now()`**。rAF 时间戳在嵌入式 webview 与 `performance.now()` 存在原点偏移,混用会让模拟时间跑快 ~4 倍(`frame()` 内已统一)。
2. **笔刷方向角必须用速度方向的 EMA 平滑**(`b.dirAngle`),不能用逐步位移的 `atan2`——120Hz 微步长下方向逐帧乱跳,nib 宽度因子震荡,墨迹碎成"粗节点+细管"(blob-and-stick)。这是验收 3.5→4.7 的主因。
3. **笔迹渲染用四边形条带填充**(相邻四边形共享边缘+笔头单圆帽),不要用圆头线段——步长接近线宽时圆帽必然串珠。
4. **精灵图形是"印刷一次"模型**(`print: true`,淡入 0.3s 后停止绘制):持久画布上每帧叠印 4.5 秒必糊成色块。运动型图形(鸟/蝶/小鱼/气泡)才持续轻印(alpha ~.13)留轨迹。
5. **光标环只能画在 fx 层**(每帧清除),画进 ink 层会留下圆环轨迹污染(初版验收 3.5 分的主要扣分点)。且仅在笔刷缓停(速度<220×scale 持续 0.35s)时显示,原版是间歇性的。
6. **编舞时间 = 歌曲时间 + 4s** 视频前导;`DURATION=244`(视频)vs 歌曲 233.7s。偏移已被 5 处独立对齐验证(唇 91s、大喷溅 70.5s、高潮 172.7s 等)。
7. **随机数一律用 `state.rng()`**(mulberry32 种子化,`rand()` 封装),`Math.random()` 会破坏回放确定性。回放时恢复 `recording.seed`(含 noise 与 rng 种子)。
8. **seek 会使录制失效**(`state.recording = null`,设计如此——混合时间轴无法作为一次手势回放)。回放中禁用 seek。
9. `window.__inkState = state` 是留给自动化测试的调试句柄(页面 console/evaluate 可用)。
10. 黑屏转场是**两阶段**:40–41.8s 黑幕+发光窗口(树下小人)→ 41.8–42.8s 回白纸+深色戴帽人剪影(画在 fx 层)。曾经黑幕全程盖住第二阶段,这是真 bug 已修。
11. 148–151s 墨滴模式**抑制一切 cue 精灵**(只留竖直滴落+尾迹+落点溅射),混入精灵会把场景搞乱。
